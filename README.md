Definition of work-
Work is measured as the amount of operations needed in the mathematical formulation of the algorithm. The following use 1 work
    comparisons
    assignments
    arithmetic operations
    Checking set inclusion
    Inserting into containers
    Removing from containers
Loops use 1 work for each iteration, plus 1 work at the end for the final check
Many operations occur in the program that aren't required in the abstract mathematical formulation. These do not contribute to work
